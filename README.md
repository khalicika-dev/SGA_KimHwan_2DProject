# SGA_KimHwan_2DProject
갓 오브 곡괭이 모작

VS2019 x64 기반 프로젝트. DX11가 사용된 2D어드벤처장르로, 2011년에 출시된 The God of Gockgang-E 를 모방한 포트폴리오용 작품입니다.

이 작품의 특징으로는 지면을 **Line을 콜리전**으로 만들어 플레이어의 이동경로가 Line형태의 Collision과 교차하면 충돌이 발생하게 제작되었으며, 오브젝트 간 충돌에는 **OBB충돌기법**을 적극적으로 활용하였습니다.

※ Releases란에 실행파일(.exe) 및 시연 영상(.mp4) 첨부됨.

## 주요 기능

- **Line 기반 지형 콜리전** 플레이어 이동 경로에 Line 콜리전과 교차 시 충돌판정. 지면 타입일 시 착지, 벽 타입일 시 미끄러짐.
- **OBB 기반 캐릭터 콜리전** — 플레이어와 적 혹은 장비나 전리품 등 OBB충돌 시 상호작용이 발생함.
- **HLSL기반 셰이더** — 현재 위치, Texture, UV 등을 버퍼에 전송해 Sprite를 조립함.
- **Bleeding 파티클** — 적 타격 시 랜덤한 속도를 갖는 출혈파티클 오브젝트를 생성해 피가 튀는 효과를 연출. 2~5개 가량의 버텍스로 선을 만들어 중력을 따라 궤적을 그림(Vertex Buffer, 색상정보 ConstantBuffer 사용), 지면에 충돌 시 혈흔 텍스처를 생성하고 파티클은 소멸됨.
- **장비 착용, 골드** — 지면에 버려진 장비와 상호작용 시 장비가 장착되며 능력치가 변화함. 몬스터가 떨어트린 골드와 충돌하면 보유 골드량이 상승함.
